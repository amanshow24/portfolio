# Aman Kumar Show — Portfolio

A responsive, frontend-only portfolio built with React, Vite, and Tailwind CSS.

## Run locally

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
```

The production files are generated in `dist/`.

## Deploy to Vercel

The `main` branch is connected to Vercel. Use the repository root as the project root, `npm ci` as the install command, `npm run build` as the build command, and `dist` as the output directory. Pushing to `main` triggers a production deployment.
